# Inspiration and originality

This project is an original starter inspired by the *interaction language* of high-end WebGL portfolio sites such as Alche Studio: cinematic scrolling, floating visual planes, WebGL distortion, smooth scrolling, minimal typography, and page transitions.

It does **not** copy Alche Studio source code, copyrighted artwork, brand assets, text, layouts, or proprietary shaders.

The implementation is built from scratch with open web libraries:
- Three.js
- GSAP + ScrollTrigger
- Lenis
- Astro
- Swup / @swup/astro

Replace the placeholder copy and generated project-card art with your own portfolio material before publishing.
